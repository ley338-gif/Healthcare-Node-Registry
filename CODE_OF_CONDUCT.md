# Code of Conduct

Wir erwarten sachliche, respektvolle und professionelle Zusammenarbeit.

Nicht akzeptiert werden insbesondere:

- persönliche Angriffe oder Diskriminierung
- Veröffentlichung vertraulicher Informationen
- Nutzung realer Patientendaten
- absichtliche Umgehung von Sicherheits- oder Qualitätsprozessen
- irreführende Aussagen über Zertifizierung, Normerfüllung oder Herstellerkompatibilität

Technische Kritik ist ausdrücklich erwünscht, muss jedoch nachvollziehbar, lösungsorientiert und auf die Sache bezogen sein.
