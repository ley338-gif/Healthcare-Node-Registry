# Implementierungsbericht: Navigation & Dashboard

## Navigation

```text
Dashboard

Registry
├── Organisationsstruktur
├── Systeme
├── Verbindungen
└── Topologie

Betrieb
├── Dokumentation
├── Monitoring
└── Audit
```

Organisationen, Standorte und Abteilungen bleiben eigene Arbeitsseiten, erhalten aber einen gemeinsamen Einstieg.

## Dashboard

Das Dashboard orientiert sich am Zielbild, zeigt aber ausschließlich echte Registry-Daten. Online-/Offline-, Monitoring- und Verbindungswerte werden erst dargestellt, wenn die entsprechenden Module implementiert sind.
