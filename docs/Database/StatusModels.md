# Statusmodelle

## Documentation State

- `draft`
- `reviewed`
- `approved`
- `deprecated`
- `archived`

## Operational Intent

- `planned`
- `active`
- `inactive`
- `unknown`

Diese Werte dokumentieren eine Soll- oder Verwaltungsinformation. Sie sind kein Ergebnis von Monitoring.

## Asset Lifecycle

- `planned`
- `commissioning`
- `productive`
- `maintenance`
- `decommissioned`
- `archived`

## Document Scan Status

- `pending`
- `clean`
- `rejected`
- `scanner_unavailable`
- `not_required`

## Verbotene irreführende Statuswerte ohne Messdaten

- online
- healthy
- reachable
- live
- latency
- failed

Solche Begriffe dürfen nur bei späteren echten Messfunktionen verwendet werden.
