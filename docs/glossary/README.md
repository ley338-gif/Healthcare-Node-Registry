# Glossar

| Begriff | Bedeutung in der HNR |
|---|---|
| Application Entity (AE) | logischer DICOM-Kommunikationspartner |
| AE Title | maximal 16 Zeichen lange DICOM-Bezeichnung einer AE |
| Archiviert | nicht mehr aktiv genutzt, aber historisch erhalten |
| Audit | nachvollziehbare produkt- oder sicherheitsrelevante Ereignisse |
| Called AE | Ziel-AE einer DICOM Association |
| Calling AE | initiierende AE einer DICOM Association |
| DICOM-Knoten | registrierte AE mit Host, Port, Rolle und Diensten |
| DICOM-Verbindung | dokumentierte Beziehung von Quelle, Ziel und Dienst |
| Dokumentation | strukturierte beschreibende Registry-Felder |
| Dokument | Metadaten mit unveränderlichen Dateiversionen |
| HNR | Healthcare Node Registry |
| Registry | fachlicher Bestand von Organisationen, Systemen und Kommunikationsobjekten |
| Rolle | Bündel bestehender Berechtigungen |
| SCP | Service Class Provider; stellt einen DICOM-Dienst bereit |
| SCU | Service Class User; initiiert einen DICOM-Dienst |
| System | technische oder logische Anwendung im Organisationskontext |
| Topologie | Visualisierung des dokumentierten Sollzustands |
| Verifikation | kontrollierte C-ECHO-Prüfung; kein vollständiger Systemtest |

Statusbegriffe für Dokumente sind `draft`, `review`, `approved`, `deprecated` und `archived`. Ergänzende ältere Begriffe enthält das [Healthcare-Glossar](../Healthcare/Glossary.md); bei Widersprüchen ist vor Freigabe eine redaktionelle Entscheidung erforderlich.
