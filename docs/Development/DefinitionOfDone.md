# Definition of Done

- [ ] Anforderung und Akzeptanzkriterien erfüllt
- [ ] Scope nicht unkontrolliert erweitert
- [ ] Code Review abgeschlossen
- [ ] serverseitige Autorisierung vorhanden
- [ ] Validierung und Fehlerfälle behandelt
- [ ] Unit-/Feature-/UI-Tests ergänzt
- [ ] CI erfolgreich
- [ ] Security-Auswirkungen bewertet
- [ ] Logs auf sensible Daten geprüft
- [ ] Datenbankmigration geprüft
- [ ] Rückwärtskompatibilität bewertet
- [ ] UI folgt Designsystem
- [ ] Accessibility-Grundprüfung erfolgt
- [ ] Dokumentation aktualisiert
- [ ] Changelog aktualisiert
- [ ] Roadmap/Known Issues geprüft
- [ ] keine kritischen oder hohen ungeklärten Risiken
