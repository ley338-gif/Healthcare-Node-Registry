# Dashboard Control Center

## Ziel

Das Dashboard ist kein Stammdaten- oder CRUD-Einstieg. Es bildet die technische Systemlandschaft und ihren Betriebszustand ab.

## Informationshierarchie

1. Systeme
2. Verbindungen
3. Online-/Offline-Status
4. Dokumente
5. Topologie
6. Verbindungsübersicht
7. Monitoring
8. Letzte Änderungen
9. Schnellaktionen

## Organisationsstruktur

Organisationen, Standorte und Abteilungen bleiben als Registry-Kontext erhalten, erscheinen jedoch nicht als primäre Dashboard-Kennzahlen.

## Wahrheitsprinzip

Solange System Registry, Verbindungen, Monitoring und Dokumentation nicht implementiert sind, zeigt das Dashboard:

- den Wert `0`
- einen klaren Implementierungsstatus
- einen fachlich korrekten Leerzustand

Es werden keine simulierten System-, Status- oder Monitoringdaten angezeigt.
