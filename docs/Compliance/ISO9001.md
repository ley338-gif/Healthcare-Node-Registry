# ISO 9001 Alignment

## Status

Vorbereitung und Alignment – keine Zertifizierung und keine Konformitätsbehauptung.

## Qualitätsmanagement im Projekt

| Qualitätsprinzip | Umsetzung |
|---|---|
| Kundenorientierung | validierte Nutzerprobleme, Pilotfeedback |
| Führung | definierte Produkt- und Freigabeverantwortung |
| Einbeziehung | Reviews und klare Rollen |
| Prozessorientierung | Issue → Änderung → Test → Review → Release |
| Verbesserung | CAPA, Retrospektiven, Lessons Learned |
| faktengestützte Entscheidung | Metriken, Tests, dokumentierte ADRs |
| Beziehungsmanagement | Lieferanten- und Abhängigkeitsbewertung |

## Kontrollierte Dokumente

Dokumente erhalten:

- Titel und Zweck
- Version/Commit
- Eigentümer oder verantwortliche Rolle
- Status
- Reviewdatum
- Änderungshistorie über Git

## Abweichungen und Korrekturmaßnahmen

Fehler mit Qualitätswirkung werden:

1. erfasst,
2. eingedämmt,
3. auf Ursache untersucht,
4. korrigiert,
5. auf Wirksamkeit geprüft,
6. in Wissen und Prozesse zurückgeführt.

## Design- und Entwicklungslenkung

- Anforderungen und Akzeptanzkriterien
- Designreview
- Verifikation durch Tests
- Validierung mit Zielnutzern
- kontrollierte Änderungen
- Freigabenachweise
