# Document Control

## Dokumentstatus

- Draft
- In Review
- Approved
- Superseded
- Archived

## Steuerung

Git bildet Version und Änderungshistorie ab. Für formell freigegebene Dokumente werden zusätzlich Verantwortliche, Freigabestatus und Reviewdatum im Dokument oder in einem Register gepflegt.

## Mindestprüfung vor Release

- Inhalt entspricht tatsächlichem Produktstand.
- Links funktionieren.
- Screenshots enthalten keine sensiblen Daten.
- Norm- und Versionsreferenzen sind aktuell.
- Verantwortlichkeiten und Kontaktwege sind korrekt.
- veraltete Dokumente sind als solche markiert oder entfernt.
