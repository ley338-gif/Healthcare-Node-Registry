# Dokumentation und Dokumente

## Strukturierte Dokumentation

Organisationen, Standorte, Abteilungen und Systeme besitzen kontextbezogene Dokumentationsabschnitte. Erfassen Sie kurze, überprüfbare Angaben und vermeiden Sie Secrets, Patientendaten und unkontrollierte Freitextkopien.

## Dokumentdateien

Der Bereich **Dokumente** und die objektbezogenen Panels verwalten Metadaten, Kategorien und unveränderliche Dateiversionen. Eine neue Datei zu einem bestehenden Dokument wird als neue Version angelegt. Download und Vorschau benötigen eigene Berechtigungen.

Verwenden Sie die zutreffende Kategorie, einen nachvollziehbaren Titel und, soweit verfügbar, Gültigkeitsdaten. Archivieren Sie veraltete Dokumente; überschreiben Sie historische Versionen nicht.

Ein Dokumentstatus ist derzeit kein vollständiger formaler Vier-Augen-Freigabeworkflow. Dateien mit nicht erfolgreicher Sicherheitsprüfung können gesperrt sein. Details enthält die [Registry-Dokumentation](../Features/registry-documentation.md).
