# Einstieg, Navigation und Suche

## Zweck

Dieses Kapitel erklärt Anmeldung, Navigation und projektweite Suche.

## Anmeldung und Abmeldung

Öffnen Sie die vom Betreiber bereitgestellte HNR-Adresse und melden Sie sich mit Ihrem lokalen Benutzerkonto an. Verwenden Sie zum Beenden der Sitzung **Abmelden** im Kopfbereich. Gesperrte Konten können keine neue Sitzung beginnen.

## Arbeitsbereiche

Die linke Navigation führt zu Dashboard, Organisationsstruktur, Systemen, Dokumenten, Topologie, Tests, Audit und Einstellungen. Nicht erlaubte Bereiche oder Aktionen können ausgeblendet beziehungsweise serverseitig abgewiesen werden.

## Globale Suche

Die Suche im Kopfbereich durchsucht für den angemeldeten Benutzer freigegebene Registry-Inhalte. Geben Sie einen eindeutigen Teil von Name, Kennung, AE Title, Host oder Dokumentmetadaten ein und wählen Sie einen Treffer, um den zugehörigen Workspace zu öffnen.

Suchergebnisse respektieren Berechtigungen. Ein fehlender Treffer beweist daher nicht, dass kein entsprechendes Objekt existiert. Verwenden Sie möglichst technische eindeutige Begriffe und prüfen Sie Schreibweise sowie aktive Filter.

## Dashboard

Das Dashboard fasst aktuelle Registry-, DICOM- und Testergebnisse zusammen. Kennzahlen sind eine Arbeitsübersicht und kein dauerhaftes Monitoring oder medizinischer Statusnachweis.
