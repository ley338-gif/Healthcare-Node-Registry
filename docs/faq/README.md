# Häufig gestellte Fragen

## Ist die HNR ein PACS oder eine CMDB?

Nein. Sie dokumentiert Healthcare-IT- und DICOM-Zusammenhänge und ergänzt vorhandene Systeme.

## Speichert die HNR Patientendaten?

Kernfunktionen benötigen keine Patientendaten. Diagnoseartefakte werden minimiert; echte Patientendaten sollen nicht hochgeladen oder als Testdaten verwendet werden.

## Ist die Topologie ein Live-Monitoring?

Nein. Sie zeigt den registrierten Sollzustand. Testergebnisse sind zeitpunktbezogene Diagnosen.

## Warum sehe ich einen Bereich oder Treffer nicht?

Navigation, Suche und Aktionen beachten serverseitige Berechtigungen. Wenden Sie sich bei begründetem Bedarf an die Benutzeradministration.

## Bedeutet ein erfolgreicher C-ECHO, dass alle DICOM-Dienste funktionieren?

Nein. C-ECHO bestätigt nur Association und Verification.

## Gibt es eine öffentliche API?

Derzeit ist keine öffentlich freigegebene, versionierte Produkt-API dokumentiert.

## Ist das Produkt ISO-zertifiziert oder ein Medizinprodukt?

Nein. Die Unterlagen beschreiben Alignment und Qualitätsgrundsätze, keine Zertifizierung, Konformitätszusage oder Medizinproduktezulassung.
