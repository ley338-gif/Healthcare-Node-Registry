# API-Referenz

## Aktueller Status

Die aktuelle HNR besitzt keine öffentlich freigegebene, versionierte Produkt-API. Browserrouten, Inertia-Props, interne JSON-Suchergebnisse und Controller sind Implementierungsdetails der Webanwendung und kein stabiler Drittanbieter-Vertrag.

Vor Veröffentlichung einer API sind Ressourcen, öffentliche Kennungen, Versionierung, Authentisierung technischer Identitäten, Autorisierung, Pagination, Fehlerformat, Rate Limits, Audit, Abkündigung und Betriebsgrenzen festzulegen.

Eine zukünftige API muss vorhandene Services, Policies, Validierung und Auditmechanismen wiederverwenden. Dokumentation einzelner Endpunkte wird erst nach Implementierung, Sicherheitsprüfung und Produktfreigabe ergänzt.

Strategische Grundlagen: [Integrations- und API-Strategie](../product-book/08-integrations-und-api-strategie.md) und [ADR-0010](../Decisions/ADR-0010-import-export.md).
