# ADR-0007: Topology Library

- **Status:** Proposed

## Präferenz

Vue Flow wird als bevorzugte Bibliothek in einem isolierten Spike geprüft.

## Akzeptanzkriterien

- kompatible Lizenz
- aktive Wartung
- Custom Nodes und gerichtete Kanten
- Filter und Detail-Drawer
- Tastaturbedienung und Fokussteuerung
- realistische Performance bei 100, 500 und 1.000 Nodes
- Export- oder Druckstrategie
- Offline-Build ohne CDN

## Entscheidung

Nach dokumentiertem Spike entweder Vue Flow akzeptieren oder eine begründete Alternative wählen.
